## 上位候補の詳細

### 1. OpenTelemetryを初めて計装して、ローカルCollector＋Jaegerでトレースを1本見るまで

#### 概要

Express（またはHono）の小さなHTTP APIに OpenTelemetry の auto-instrumentation を入れ、OTLP/HTTP（4318）でDocker上のCollectorへ送り、Jaeger UI（16686）でトレースを確認する。さらに業務的な意味のある手動spanを1つ足して、自動計装だけでは見えない区間が可視化されることまでを検証ログにする。

#### なぜ今よさそうか

- Zennで公式の記事投稿コンテスト「OpenTelemetryの知見を、記事にしよう」が **2026-06-19〜2026-08-10** で開催中。テーマ需要が可視化されており、締切前の投稿は読まれやすい。
- OpenTelemetryは2026年時点でオブザーバビリティの事実上の標準。一方で「JS SDKは単一パッケージが無く、必要な物を自分で組み合わせる」構成のため、新人が確実に詰まる＝記事の価値が出る。
- SaaSに送らずローカルCollectorで完結できるため、認証・課金ゼロで検証できる。

#### 新人が検証しやすい理由

`docker compose` でCollectorとJaegerを立て、Nodeアプリ側は数パッケージ入れて起動時に読み込むだけ。可視化はJaeger UIをPlaywrightでスクリーンショットすればよい。

#### 想定読者

- 計装をやったことがない新人〜実務2年目
- 「トレースって結局どう見えるの？」を画面で知りたい人

#### タイトル案

1. OpenTelemetryを初めて触って、ローカルCollectorにトレースを出すまでにやったこと
2. 計装未経験の新人がNodeのAPIをOpenTelemetryで計装して、Jaegerでトレースを1本見るまで
3. OpenTelemetryのJS SDKでパッケージ選びから詰まった話（ローカル完結で検証）

#### 検証でやること

- 最小HTTP API（3〜4エンドポイント、うち1つは意図的に遅い処理）を用意する
- OTel Collector + Jaeger を docker compose でローカル起動する
- auto-instrumentation を入れて、無改造でどこまでspanが出るか確認する
- 手動spanを1つ足して、自動計装との差分を見る
- Jaeger UI をPlaywrightで開いてスクリーンショットを撮る

#### 検証手順

1. Node + Express の小さなAPIを作り、`/slow` に人工的な遅延を入れる
2. `otel-collector-config.yaml`（OTLP receiver 4318 → Jaeger exporter）と docker compose を書き、`docker compose up -d` で起動する
3. `@opentelemetry/sdk-node` と `@opentelemetry/auto-instrumentations-node` を入れ、起動時に読み込む（`--import` かエントリ先頭）
4. `curl` で全エンドポイントを叩き、Collectorのログにspanが届いているか確認する
5. Jaeger UI（`http://localhost:16686`）をPlaywrightで開き、サービス名で検索してトレース詳細をスクリーンショット
6. `tracer.startActiveSpan()` で手動spanを1つ追加し、トレースの階層がどう変わるか比較する
7. 詰まった点（パッケージ構成、エクスポータのendpoint、サービス名が出ない、spanが届かない等）をすべて記録する

#### 記事構成案

1. はじめに
2. なぜOpenTelemetryを試すのか（コンテストと業界標準化）
3. 事前に調べたこと（SDKがモノリシックでない話）
4. 環境構築（Collector + Jaeger をローカルに）
5. auto-instrumentationだけで何が見えたか
6. 手動spanを1つ足して見えた差分
7. 詰まった点（パッケージ選び / endpoint / サービス名）
8. 触ってみて分かったこと
9. どんな人に向いていそうか
10. まとめ

#### 差別化ポイント

既存の日本語記事はSaaS（Datadog等）へ送る前提が多い。**完全ローカル・認証ゼロ**で「トレースが見える」までを最短で通し、パッケージ構成でつまずいた具体的なエラーを載せる点で差別化する。
