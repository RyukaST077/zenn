A maintainer running `claude -p --permission-mode dontAsk` in unattended CI who needs one audited Python helper to execute and must distinguish a real permission denial from an upstream provider failure (`practice/agent/agent-practice-claude-dontask-allow-rule-boundary-20260818-0521.md`).
