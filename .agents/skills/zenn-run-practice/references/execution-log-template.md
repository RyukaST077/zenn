# Execution log contract

Include: plan path; environment and versions; start/end time; chronological command table; redacted relevant output; observations; generated files; failures and attempted fixes; deviations; verification results; reproducibility notes; unresolved limitations; article-safe facts. Separate observed facts from interpretation.

Also record the effective sandbox, product-specific telemetry/preference controls, capability-gate results, pinned lifecycle-command help, cleanup confirmation, and any known external-state pre/post assertions. Do not claim that path-specific assertions prove the absence of every external write; that guarantee belongs to the sandbox or outer isolation boundary.
