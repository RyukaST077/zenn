# Research report contract

Include: assumptions; existing-article exclusions; searched queries; domestic sources; international sources; 5-10 viable candidates with scores; excluded candidates and reasons; top three; selected topic; half-day verification outline; risks and stop conditions. Every current factual claim must have a URL and access date.

Identify the reader's prior knowledge, new concepts, concrete situation, learning goal, and first observable success. Explain how each verification item contributes to the reader's goal. Include the JSON article contract defined in [article-contract.md](../../../../strategy/article-contract.md) under `## 記事契約`, including explicit `experimentId` and `arm` fields. Preserve any assignment supplied in the prompt.
